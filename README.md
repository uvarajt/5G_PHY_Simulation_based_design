This module focuses on the end-to-end simulation of the 5G NR physical layer, exploring both theoretical foundations and practical implementation using MATLAB. 
It covers the evolution of wireless standards, key LTE/NR technologies, and detailed PHY/MAC procedures critical to 5G communication.

Topics Covered:
1. Evolution of Wireless Standards
2. 5G NR Numerology
3. MAC-PHY Interface
4. CRC, Segmentation, and LDPC Coding
5. Modulation, Rate Matching, and Interleaving
6. Code Block Concatenation & Scrambling
7. RF Chain Processing
8. Control Channel Signal Chain Design

Hands-on MATLAB exercises reinforced each concept, bridging the gap between standard specifications and real-world implementation.
